# bynana.my.id Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Situs link affiliate satu pemilik dengan katalog produk bernomor, dua tema publik lengkap (A Blok warna, C Kartu pastel) yang dipilih dari admin, panel admin untuk HP, dan pencatatan klik tanpa cookie.

**Architecture:** Satu aplikasi SvelteKit (adapter-node) dengan SQLite (`better-sqlite3`) di folder data di luar kode. Logika domain ada di `src/lib/server/*` sebagai fungsi murni yang menerima `Database` sehingga mudah dites. Halaman publik dirender di server dengan JavaScript seminimal mungkin; tema dipilih per request dari tabel `settings`, dan tiap tema punya komponen halaman sendiri di `src/lib/themes/<id>/`.

**Tech Stack:** Node 22+ (produksi v24), SvelteKit 2.70.3, Svelte 5.57.3, Vite 7.3.7, @sveltejs/vite-plugin-svelte 6.2.4, @sveltejs/adapter-node 5.5.7, better-sqlite3 13.0.3, sharp 0.35.5, TypeScript 5.9.3, Vitest, Playwright (browser sudah terpasang di mesin).

**Spec:** `docs/superpowers/specs/2026-11-01-bynana-design.md`

## Global Constraints

- Semua teks UI berbahasa Indonesia sehari-hari, suara "aku" di halaman publik; tanpa emoji, tanpa eyebrow, tanpa gradien, tanpa angka karangan (taste-skill + anti-slop).
- Tema publik: `blok` (A) dan `pastel` (C). Warna A: `#FFFFFF`, `#141414`, `#FF4F9A`, `#D7F75B`, `#F1F1F1`, `#FFD3E6`, `#EEF9C4`; huruf Bricolage Grotesque. Warna C: `#FFF0F4`, `#2A0F1F`, `#FFC2D6`, `#BDE8D5`, `#FFD39A`; huruf Unbounded (judul) + Figtree (teks). Font di-host sendiri (tanpa Google Fonts saat runtime).
- Port 3200, `DATA_DIR` default `./data` (produksi `/opt/bynana-data`), heap Node 256 MB.
- Tidak ada secret di repo. `.env` di-ignore; `.env.example` hanya berisi nama variabel.
- Nomor produk unik, tidak pernah dipakai ulang; nomor otomatis = nomor terbesar yang pernah ada + 1.
- `/go/` hanya meneruskan ke URL yang tersimpan di database.
- Pembaca link: hanya host toko dikenal, ≤5 redirect, timeout 5 detik, IP privat ditolak, user agent `bynana-link-reader/1.0 (+https://bynana.my.id)`.
- Toko yang dikenal: `shopee`, `tiktok`, `tokopedia`, `lazada`, `lainnya`.
- Commit ke branch `dev`, tidak ke `main`.

## Review Focus

1. Link affiliate yang ditempel berisi spasi, teks tambahan dari aplikasi Shopee ("Cek ... di Shopee! https://..."), atau duplikat: harus tetap diambil URL-nya, dan duplikat ditandai bukan dibuat dua kali. → tes `parseBulkLines` (Task 3).
2. Pengunjung mengetik "no.459", "#459", "459 " atau "No 459" di pencarian: harus langsung ke produk 459. → tes `parseQuery` (Task 5).
3. Nomor yang diarsipkan atau belum ada dibuka lewat `/459`: halaman jelas + kolom cari, status 404, bukan error. → e2e (Task 11).
4. Foto dari HP berukuran besar (HEIC/12 MB) atau bukan gambar: ditolak dengan pesan jelas, bukan crash. → tes upload (Task 4).
5. Tema diganti saat pengunjung sedang membuka halaman: request berikutnya memakai tema baru tanpa cache basi (header `Cache-Control` publik pendek). → e2e (Task 11).
